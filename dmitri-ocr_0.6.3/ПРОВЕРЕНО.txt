РЕАЛЬНЫЙ OCR
Использован Tesseract.js 5.1.1 / WASM, тот же API и версия ядра, что в приложении.
Четыре контролируемых изображения с русским текстом:
две строки, четыре строки, слабое последнее слово и маленький шрифт.
Для каждого режима выполнено по три распознавания каждого изображения.
Модели загружены из локальных файлов тестового окружения.

В этих изображениях:
Быстрый режим: 6 ошибок символов суммарно; последнее слово сохранено в 3 из 4 случаев.
Точный режим: 0 ошибок символов в этих четырёх конкретных изображениях; последнее слово сохранено во всех 4.
Медиана времени по случаям на Linux CPU: 125,5 мс и 320,5 мс.
Это сравнение одновременно меняет модель и подготовку изображения; отдельный вклад каждого изменения не измерен.
В точном режиме контрольное слабое последнее слово «ключ» восстановлено.

Подробные результаты: benchmark-ocr-local.json.
Это не тест на iPhone, не реальные игровые кадры и не обещание безошибочного распознавания.
Проверка новой версии на физическом устройстве, с камерой и синтезом одновременно, ещё не выполнена.
