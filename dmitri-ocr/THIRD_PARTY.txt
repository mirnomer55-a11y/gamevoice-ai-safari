GameVoice AI — Dmitri + OCR experiment 0.6.0

This folder contains the experimental integration source. The camera,
image preprocessing, OCR configuration and system speech implementation are
derived from the user's working GameVoice AI web app 0.5.0.

Russian neural voice and runtime are reused from ../neural-lab/.
Sources, exact package versions, model revision and licenses:
../neural-lab/THIRD_PARTY.txt
https://huggingface.co/rhasspy/piper-voices
https://github.com/microsoft/onnxruntime/tree/v1.24.3
https://github.com/diffusion-studio/piper-wasm
https://github.com/rhasspy/espeak-ng

The integrated neural speech code is distributed under GPLv3-or-later,
with the individual components retaining their original licenses.
License text is included in ../neural-lab/sources/ESPEAK-GPL3.txt.

OCR: Tesseract.js 5.1.1 and tesseract.js-core 5.1.1, Apache-2.0.
https://github.com/naptha/tesseract.js/tree/v5.1.1
https://github.com/naptha/tesseract.js-core
Russian fast language data is loaded from the existing configured source:
https://tessdata.projectnaptha.com/4.0.0_fast

No server receives camera frames or text for synthesis. Session metrics
are exported only when the user presses the save button.
