Проверка доступа владельца

Эта страница создаёт один код для проверки без списания звёзд. Для выдачи доступа потребуется выполнить команду в своей базе Cloudflare. Посетитель без доступа к базе выдать себе лицензию не сможет.

Токен бота и секретные ключи здесь не нужны. Код и команда создаются в вашем браузере и не отправляются на сервер этой страницей.

1. Команда для вашей базы

Откройте в Cloudflare: D1 → gamevoice-access → Console. Выполните всю команду ниже один раз.

2. Код активации

После успешного выполнения команды скопируйте код и активируйте его в том браузере iPhone, который будете использовать.

Открыть страницу доступа Код используется для одной привязки браузера. Он не появится в Telegram-боте и не отмечается как оплаченная покупка. Страница не меняет цену и не открывает продажи. Сохраните код до активации: обновление страницы удалит показанные значения.

Сначала убедитесь, что таблицы базы уже подготовлены.
